GitLab Extra Privacy Policy

Last updated: 31 Oct 2026

Scope

This policy covers the GitLab Extra Chrome extension, published by Ventura TRAVEL for developers using Ventura Travel's GitLab. The extension adds merge request filters and context about affected apps, CI checks and desired deployment versions. Access to private GitLab projects requires your existing authorized account.

Information the extension accesses

The extension runs only on https://gitlab.venturatravel.org/. It reads your signed-in GitLab username to create personal filters. When you open a preview or detail view, it requests the pipeline and job metadata, app artifacts, build scope information, merge request titles, commit history and repository configuration needed for that view.

This information is used only to display the requested GitLab context and filters. It is not used for advertising, profiling, creditworthiness or lending.

Network access and permissions

Requests go directly to the same GitLab instance over HTTPS using your existing browser session. The extension does not read passwords, API tokens or session cookies, and does not bypass GitLab access permissions. It requests no access to other websites.

Links to GitLab jobs, comparisons and ArgoCD open only when you choose them. Those services handle access under their own policies.

Storage and retention

The extension processes and temporarily caches GitLab information and interface selections in the current page's memory. This information is cleared when that page is reloaded or closed. The extension does not save this information in permanent extension storage or maintain a separate server or user database.

Sharing and tracking

The extension does not upload GitLab information to an external service, sell or rent data, or share it with third parties. It does not include advertising, analytics or tracking. It does not record browsing history or log your clicks or keystrokes. All executable extension code is included in the installation package; repository contents are read as data and are not executed.

Your choices

You can close or reload the GitLab page to clear the extension's temporary data, or disable or uninstall the extension in Chrome. GitLab itself retains information under its own policies; uninstalling this extension does not delete GitLab records.

Contact

Questions about this policy can be sent to the Ventura Travel IT team through normal internal support channels or through the GitLab Extra issue tracker.
